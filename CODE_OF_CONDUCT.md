# Code of Conduct

This project expects respectful, constructive collaboration.

## Expected Behavior

- Be direct about technical problems while staying professional toward people.
- Keep feedback specific, actionable, and grounded in evidence.
- Respect the project's local-first security and privacy boundaries.
- Assume contributors may be using different operating systems, shells, Python
  versions, or Codex setups.

## Unacceptable Behavior

- Harassment, insults, personal attacks, or discriminatory language.
- Publishing another person's private data, credentials, logs, ChatGPT URLs,
  thread IDs, browser profile data, or local runtime artifacts.
- Pressuring maintainers or contributors to bypass security, privacy, or
  confirmation boundaries.

## Reporting

For conduct concerns, contact the repository maintainer privately. For security
or private-data exposure, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
